# Learning: Strategic Project Remapping

Date: 2026-01-20

## Observation
To align with the Quince "Staff Data Scientist" role, we needed to demonstrate "Automated Bidding" and "Causal Inference" experience, which were not explicitly named in the original project titles.

## Insight
We successfully remapped existing projects using "Strategic Translation":
*   `stock_price_target_modelling` (Trading) -> "Autonomous Trading & Bidding Agent" (Bidding logic is analogous).
*   `Marketing-Analytics-Assistant` -> "Statistical Attribution" (Focus on outcome: incremental lift).

## Actionable Rule for Future
When creating portfolio pages for specific JDs, do not just list projects. **Rename and reframe** them to match the JD's specific vocabulary (e.g., "Trading" -> "Bidding", "ETL" -> "Feature Pipelines"). This is "Strict Honesty with Strategic Framing."
