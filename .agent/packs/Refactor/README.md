# PAI Pack: Refactor

## Overview
Executes the code hygiene & refactoring ritual (The Cleanse). Focuses on DRY principles, readability, and artifact safety.

## 7-Phase Algorithm Mapping (The Cleanse)
- **OBSERVE**: Scan for code smells, duplication, and stale TODOs.
- **THINK**: Assess impact of changes on existing tests.
- **PLAN**: Define refactor scope (file-level or module-level).
- **BUILD**: Backup sensitive files.
- **EXECUTE**: Apply structural improvements.
- **VERIFY**: Run linting and unit tests.
- **LEARN**: Capture refactoring patterns in `.pai/tasks/lessons.md`.

## Installation
`Install the Refactor pack from .agent/packs/Refactor/`
