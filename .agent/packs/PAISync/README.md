# PAI Sync Ritual (PAI Pack)

## Overview
This pack executes the **"Save Game"** ritual for your project. It captures architectural decisions, triggers IDE synthesis, ensures telemetry is processed, and syncs Global Portfolio properties.

## When to Run
- End of day or before context switching to another project.
- Before long breaks to persist decision state.
- After significant refactors or complex debugging sessions.

## Installation
Run: `Install the PAISync pack from .agent/packs/PAISync/`
The AI will execute the 5-phase `INSTALL.md` wizard.
