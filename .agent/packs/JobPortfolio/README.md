# PAI Pack: JobPortfolio

## Overview
Create a new tailored portfolio page for a specific job opportunity.

## 7-Phase Algorithm Mapping (Tailoring)
- **OBSERVE**: Intake JD and existing user persona.
- **THINK**: Identify key themes/keywords to highlight.
- **PLAN**: Design the tailored sub-page structure.
- **BUILD**: Clone baseline portfolio files.
- **EXECUTE**: Inject agentic summaries and custom badges.
- **VERIFY**: Visual audit of the tailored page.
- **LEARN**: Save job context to `.pai/job_contexts/`.

## Installation
`Install the JobPortfolio pack from .agent/packs/JobPortfolio/`
