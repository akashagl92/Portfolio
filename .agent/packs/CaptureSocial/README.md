# PAI Pack: CaptureSocial

## Overview
Capture HTML animations as social media videos/GIFs (LinkedIn, Instagram, X, Substack).

## 7-Phase Algorithm Mapping 
- **OBSERVE**: Detect target element and desired aspect ratio/format.
- **THINK**: Check for performance bottleneck during record.
- **PLAN**: Define capture duration and FPS.
- **BUILD**: Initialize the capture skill.
- **EXECUTE**: Run the browser capture.
- **VERIFY**: Check the output video/GIF for visual artifacts.
- **LEARN**: Update capture settings in `.pai/state/`.

## Installation
`Install the CaptureSocial pack from .agent/packs/CaptureSocial/`
