# PAI Pack: ResearchSpawn

## Overview
Spawns a multi-agent research task with quick/standard/extensive/deep modes.

## 7-Phase Algorithm Mapping
- **OBSERVE**: Define research goals and depth level.
- **THINK**: Check budget and time constraints for spawning.
- **PLAN**: Select research patterns.
- **BUILD**: provision sub-agent environment.
- **EXECUTE**: Spawn sub-agent.
- **VERIFY**: Collect and synthesize research findings.
- **LEARN**: Update knowledge base with citations.

## Installation
`Install the ResearchSpawn pack from .agent/packs/ResearchSpawn/`
